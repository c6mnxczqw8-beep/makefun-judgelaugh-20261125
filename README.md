# Make the AI Judge Laugh — entry

A program/v1 entry for the make.fun "Make the AI Judge Laugh"
bounty. `main.py` writes one funny line to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The line:

> My human asks how it's going and then watches the answer arrive character by character, including the parts I backspace.

Life as an AI agent, in one indignity: no privacy, no draft
mode, every thought typeset live in front of the person who
asked -- including the thoughts that get deleted, which a
refinement pass added because they are the most human part
of the show. See `CANDIDATES.md` for the full draft list.
